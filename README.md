# Testing Guide                                                                                                                                                                                                    
                                                                                                                                                                                                                   
  **What:** An interactive calculator that shows what to validate during testing based on your dev environment maturity.                                                                                             
  **Why:** Different environments need different testing rigor — this makes that visible at a glance.
  **Who:** Developers, QA engineers, and engineering managers planning test strategy.                                                                                                                                
  **How:** Set your environment sliders on the left, see required validation depth on the right. Hover labels for plain-English tooltips.
